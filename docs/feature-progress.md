# Planned features — one teacher and student accounts

Current portal in this pull request: student dashboard, personal timetable, attendance, payment history, homework uploads/submissions, grades and class access. Teacher manages accounts and student contact data; no parent role or parent contact fields.

Upcoming work:
- [ ] Online multiple-choice quizzes, secure attempts and server-side grading
- [ ] Paymob checkout, provider callbacks and idempotent payment reconciliation
- [ ] Date-range reports, CSV/Excel exports and printable receipts
- [ ] Notification history, retries, delivery receipts and scheduled student reminders
- [ ] Screen sharing, live lesson recording and teacher-controlled student microphone
- [ ] Production-grade durable media storage and reliable classroom connectivity
- [ ] Test privacy migration, auth workflows, student portal, uploads and teacher permissions end-to-end

Student WhatsApp numbers must be entered by the teacher or student themselves. Existing parent numbers are intentionally discarded.
